# Technical German PWA, 500 terms

Includes 100 core technical terms plus 400 practical workplace collocations, in German, English and Portuguese.

Modes: German-English, English-German, German-Portuguese, Portuguese-German; category selection; quiz; flashcards; error review; offline use; local progress.

## Run
1. Install Node.js 18 or newer.
2. `npm install`
3. `npm run dev`

## Publish
Run `npm run build` and upload `dist` to a static HTTPS host. After deployment, install with the browser's Add to Home Screen / Install App option.
